## ABQ adaptation: Mon + Fri (your tweak)

Catskill solved late events with **one** Tuesday send. ABQ plan uses **two** sends:

| Send | Coverage | Catskill analog |
|------|----------|-----------------|
| **Monday AM** | Mon–Thu | Early-week planning (editions 1–23 on Monday) |
| **Friday AM** | Fri–Sun + late adds | Tuesday rationale applied to weekends |

Everything else copies Catskill: same bullet format, same hook, same CTAs, same monetization timeline.

## Edition #1 anatomy (copy this)

**Word count:** ~929  
**Sections:** 3 (hook, Weekly Breakdown, one extra block)  
**Monetization:** None  
**Event bullets:** ~40 across 7 days

### Structure

```
1. Title line + date + disclaimer
2. Welcome / share CTA (1–2 paragraphs)
3. Editorial hook section (seasonal, local news angle)
   e.g. "The Mountains Are Open 🏔️"
4. Weekly Breakdown ❤️‍🔥
   Monday 27th
   - Venue, Town — event detail
   Tuesday 28th
   - ...
   [through Sunday]
5. Optional extra block (maker market, spotlight, recipe)
6. "Belly Up" — event submission CTA
   "Let us know any events via IG @catskillcrew or email"
7. Forward CTA + Subscribe
```

### Bullet format (exact pattern)

```
- Foxfire Mountain House, Mt Tremper - Half priced bottles of select wine… sip sip 🍷
- Colony, Woodstock - World-Famous Open Mic hosted by Brendan O'Shea! Sign ups from 7 to 8pm and beyond
```

**Pattern:** `- Venue, Location - Description`  
Optional emoji at end. Times inline. Link words like "more info" when available.

### Opening hook examples (early issues)

- Seasonal: ski lifts open, winter weather
- Community: subscriber milestone ("We crossed 1,200+")
- Local business news: new cafe opening, industry night

### Footer (pre-monetization)

```
Let us know any events / establishments you would like to be added to this list via IG @catskillcrew or email

If someone forwarded this to you, time to make the leap and join the crew!

Subscribe
```

- [ ] Target 800–1,200 words per event send
