### White space

Nobody in ABQ runs a **Catskill-style day-by-day Weekly Breakdown** with a consistent local voice and resident-first curation.

**Closest threats:**
- **ABQtodo** — owns calendar SEO, no voice
- **Morning Albuquerque** — owns daily inbox, no venue-by-day events
- **ABQ Mom** — owns family weekly, different audience

**Your edge:** Copy Catskill's product (day-by-day bullets, local voice, Mon/Fri reliability). Beat them on execution, not format innovation.

### Newsletter Phase 0 — Research (done)

- [x] Catskill cadence playbook

### Newsletter Phase 1 — Beehiiv MVP (manual, 4–8 weeks)

1. Create beehiiv publication (consumer brand — separate from admin civic app)
2. Set up two segments or separate templates: **Monday Events**, **Friday Events**
3. Optional third: **News** (Tue–Thu or as-needed)
4. Send edition #1 equivalent: zero monetization, share CTA only
5. First sponsor ~week 5 (Catskill pattern)
6. Track: open rate, subs, events listed per send

### Newsletter Phase 1 content targets

| Metric | Target |
|--------|--------|
| Mon + Fri sends | 8 consecutive weeks |
| Words per event send | 800–1,200 |
| Events listed per week | 50+ across both sends |
| Subscribers (90 days) | 500+ organic |
| Monetization | None until week 5 |

### Newsletter Phase 2 — Pipeline (after habit proven)

- Use civic pipeline transcripts → council highlight drafts (Legistar sync already live)
- Optional event DB in Neon
- Sponsor outreach (Fri send = weekend premium inventory)

### Newsletter Phase 3 — Monetization (Catskill arc)

Follow [`STRATEGIC-REFERENCE.md`](../catskill-crew/STRATEGIC-REFERENCE.md):

1. Newsletter sponsors
2. Ticketed / sponsored events
3. Local pass (Crew Card equivalent)
4. Defer: merch, games, snail mail
